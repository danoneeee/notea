# Note Flow (MVP)

Этот файл фиксирует текущую реализацию, чтобы легко править в следующих итерациях.

## Что реализовано

- Маршрут создания заметки: `/notes/new`
- Экран мастера на 4 шага:
  - Шаг 1: базовая информация о чае
  - Шаг 2: параметры заваривания
  - Шаг 3: дескрипторы вкуса через круг с раскрытием подкатегорий
  - Шаг 4: оценки по категориям звездами + свободные заметки
- Кнопка перехода "Новая заметка" на главной странице
- Черновик сохраняется в `localStorage` под ключом `notea_note_draft`
- На шаге 3:
  - сначала выбирается семейство вкуса в круге
  - затем круг переключается в режим подкатегорий выбранного семейства
  - выбираются уже подкатегории (до 8)
- На шаге 4:
  - оценки ставятся звездами отдельно для `aroma`, `taste`, `aftertaste`, `balance`

## Где это в коде

- Страница мастера: `src/pages/NewNotePage.vue`
- Круг дескрипторов: `src/components/DescriptorWheel.vue`
- Роуты: `src/router/index.ts`
- Кнопка входа в мастер: `src/pages/HomePage.vue`

## Как править дальше

- Добавить вложенные уровни дескрипторов (семейство -> подсемейство -> нота)
- Для каждого дескриптора добавить интенсивность (1-5)
- Вместо localStorage подключить сохранение в backend API
- Добавить экран просмотра сохраненной заметки
